MULUNGUSHI BUS QUEUE SYSTEM - WEBSITE FILES

Files:
- index.html: public landing page
- privacy.html: starter privacy notice (must be reviewed and completed)
- terms.html: starter terms of use (must be reviewed and completed)

BEFORE PUBLISHING:
1. Replace REPLACE-WITH-REAL-EMAIL and REPLACE-WITH-REAL-PHONE in index.html.
2. Complete the contact email and date placeholders in privacy.html and terms.html.
3. Review the privacy notice so it accurately describes the data your real app collects,
   how Meta WhatsApp messaging is used, retention, sharing and user rights.
4. Do not claim features are live if they are still only planned. The page currently
   describes the platform as proposed/intended and labels queue figures illustrative.

PUBLISHING WITH GITHUB PAGES:
1. Create/sign in to a GitHub account.
2. Create a new public repository, e.g. mulungushi-bus-queue-website.
3. Upload index.html, privacy.html and terms.html to the repository root.
4. Open repository Settings -> Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select branch main and folder /(root), then Save.
7. Wait for GitHub Pages to publish. The public URL will look like:
   https://YOUR-GITHUB-USERNAME.github.io/mulungushi-bus-queue-website/
8. Open that URL in a private/incognito browser window to confirm it is public.
9. Enter the public URL in Meta Business Details -> Business website.

Note: GitHub Pages may take a few minutes to publish. A public website URL does not
replace any separate Meta business verification or account permission requirements.
